# Afia: Local AI Lab & Research Assistant

## Overview
A custom, privacy-focused AI research assistant designed to parse technical documentation, streamline experiment setup steps, and provide in-depth scientific explanations without relying on cloud paywalls or restrictive web filters.

## Features
- **Local RAG Integration:** Queries local PDF manuals, research papers, and datasheets for precise retrieval.
- **Deep Technical Guidance:** Configured with custom system prompts to explain hardware pinouts, software dependencies, and step-by-step experiment execution.
- **Privacy First:** Runs locally using open-source models (Ollama) to ensure data confidentiality.

## Tech Stack
- **Language:** Python
- **LLM Runner:** Ollama (Llama 3 / Qwen 2.5)
- **Frameworks:** LangChain / LlamaIndex, PyPDF
